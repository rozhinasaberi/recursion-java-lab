# RojinaSaberi_COMP254Lab3

A COMP254 recursion lab with a Streamlit tutor app that demonstrates recursive thinking through interactive examples.

## What This Project Is About

This repository contains Java recursion exercises for star patterns, vowel counting, and directory searching. It now also includes a Streamlit tutor app that visualizes each problem as a sequence of smaller calls so users can understand the recursive mindset instead of only seeing final output.

This is a **Java recursion project with an AI tutor style Streamlit app**.

## What The Tutor App Teaches

- how recursion breaks a big problem into smaller versions of itself
- how base cases stop a recursive process
- how recursive pattern generation works
- how recursive search explores a branching structure

## Project Structure

- `app.py` - Streamlit tutor app
- `requirements.txt` - Python dependencies for the tutor app
- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`
- `src/com/exercise3/rojina/saberi/`
- `src/module-info.java`

## Run The Streamlit App

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Open The Java Project

Import into Eclipse and run the desired exercise class from the `src/` folder.
