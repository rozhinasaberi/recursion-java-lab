# RojinaSaberi_COMP254Lab3

A COMP254 Java lab focused on recursion and recursive problem solving.

## What This Project Is About

This lab practices recursive thinking through three separate exercises: printing star patterns, counting vowels in a string, and recursively searching directories for a file by name.

This is a **Java recursion lab**.

## Exercises Included

- `Exercise1` - recursive star pattern printing
- `Exercise2` - recursive vowel counting
- `Exercise3` - recursive file search through directories

## Project Structure

- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`
- `src/com/exercise3/rojina/saberi/`
- `src/module-info.java`

## Open Or Run

Import into Eclipse and run the desired exercise class from the `src/` folder.
